## 📖 Course Description

**Advanced Data Analysis** is a demanding, hands-on course designed to bridge the social sciences and the computational tools that are reshaping how social research is done. It introduces programming fundamentals and a research-oriented computational toolkit, from the first line of Python to the design of language-model pipelines for social scientific measurement.

### 🎼 Course Structure

The course is organised in **five movements**:

1. **Foundations** — the fundamentals of Python and numerical computing.
2. **Data** — data wrangling and the collection of digital trace data from the web.
3. **Machine Learning** — machine learning as a research practice: model selection, evaluation, tuning. It closes by confronting prediction with causation, through the machine learning methods now used for causal estimation.
4. **The Frontier** — what sets this course apart from a conventional data science curriculum: using large language models as annotators, distilling their competence into small, transparent, reproducible classifiers, and building calibrated synthetic agents that stand in for human respondents.
5. **Elective** — a session whose content the class sets collectively, according to what the final projects turn out to require.

Throughout, technical instruction is paired with a curated set of readings that supply the theoretical and ethical backdrop.

> 💡 The aim is not to make you a machine learning engineer. It is to make you a social scientist who can decide, defensibly, which computational technique answers your question, and who can implement it, validate it, and report it.

## 🎯 Learning Outcomes

By the end of the semester, students will be able to:

- ✅ write and debug idiomatic Python for data-intensive research tasks;
- ✅ acquire, clean, merge, and reshape research data from files, APIs, and web sources;
- ✅ design a supervised learning pipeline and evaluate it with metrics appropriate to the research question;
- ✅ distinguish predictive from causal questions, and apply machine learning methods built for causal estimation;
- ✅ use large language models as measurement instruments, with explicit validation against human-coded ground truth;
- ✅ distil a large model into a small, deployable classifier and justify the trade-off;
- ✅ reason critically about bias, representativeness, reproducibility, and research ethics in computational work;
- ✅ produce a complete, documented, publicly hosted research project in a GitHub repository.
